# Architecture Decision Summary

Version: 1.0

This file summarizes current decisions. Full records are in `docs/ADR/`.

1.  **Browser-based web application** --- chosen for accessibility and
    future commercialization.
2.  **Personal-first, commercial-ready** --- validate with the creator
    before investing in SaaS billing and team features.
3.  **Shared scene schema** --- static and motion outputs reuse the same
    visual definitions.
4.  **Preset-first with advanced editor** --- common results are fast;
    advanced controls are optional.
5.  **Deterministic UI compositing** --- source UI must not be
    regenerated by AI.
6.  **2.5D rendering first** --- use licensed device assets and screen
    mapping before committing to full 3D.
7.  **Guided capture before automation** --- validate a reliable
    recording workflow before automatic journey generation.
8.  **Separate rendering worker for video** --- resource-intensive
    capture and encoding do not run in the main request process.
9.  **Modular monolith by default** --- avoid premature microservices.
10. **Security, testing, observability, and rate limits are
    non-negotiable** --- include them in the initial implementation.
